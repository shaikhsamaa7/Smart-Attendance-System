# Smart Attendance Management System

## 📌 Case Study

The Smart Attendance Management System is a web-based application designed to simplify the process of recording and monitoring student attendance.

It provides a simple dashboard where teachers can view students, mark them as Present or Absent, and monitor the overall attendance percentage.

---

## 🎯 Objective

The main objective of this project is to replace manual attendance recording with a simple digital attendance management system.

The system aims to:

- Reduce manual attendance work
- Make attendance records easier to manage
- Provide quick attendance statistics
- Calculate attendance percentage automatically
- Provide a simple and user-friendly dashboard

---

## ✨ Features

- Attendance Dashboard
- Student Attendance Table

🔄 How the System Works
1. The teacher opens the attendance dashboard.
2. The dashboard displays the list of students.
3. The teacher marks each student as Present or Absent.
4. The system automatically updates the number of present and absent students.
5. The attendance percentage is calculated automatically.
6. Changes to the project are managed using Git and GitHub.
7. GitHub Actions automatically checks the project after code is pushed.
